Abstract

Verifying that microlighter highlights code containing markup inside, coincident with, and crossing highlight boundaries.

1. Markup Inside Highlight Tokens

Markup elements (e.g. <span>, <mark>) nested inside single tokens like keywords, identifiers, and strings:

function myFunction() {
    const str = "hello world";
}

2. Markup Coincident with Highlight Tokens

Markup elements whose boundaries exactly match token boundaries:

const myIdentifier = true;

3. Markup Crossing Highlight Boundaries

Markup elements spanning across multiple tokens or starting/ending mid-token:

let a = 1;
foobar + bazqux();
/* A comment with markup crossing the comment */
